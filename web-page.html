Bagaimana Internet Bekerja?

Dari Perangkat Komputer Lokal Hingga Jaringan Serat Optik Bawah Laut Global

1. Landasan Jaringan Lokal & Perangkat Keras

Setelah komputer Anda dirakit, diinstal OS, dan dilengkapi aplikasi, perangkat tersebut masih berdiri sendiri (standalone). Agar dapat terhubung ke dunia luar, komputer membutuhkan komponen hardware jaringan khusus.

💻 NIC (Network Interface Card)

Adapter Ethernet atau modul Wi-Fi yang mengonversi data digital komputer menjadi sinyal listrik atau gelombang radio.

🔀 Switch

Titik penghubung antarperangkat di dalam satu jaringan lokal (LAN). Mengarahkan data berdasarkan alamat fisik (MAC Address).

🌐 Router

Perangkat cerdas yang menentukan rute terbaik (routing) untuk meneruskan data keluar dari jaringan lokal menuju jaringan lain.

📡 Modem

Mengubah sinyal digital dari router menjadi sinyal analog/cahaya agar dapat melintasi jaringan ISP (Internet Service Provider).

Catatan: Pada perangkat Wi-Fi rumahan modern, fungsi Switch, Router, dan Modem umumnya telah digabungkan menjadi satu perangkat terpadu.

2. Sistem Pengalamatan: MAC, IP Address, dan DNS

Agar data tidak tersesat di antara miliaran komputer di dunia, internet menggunakan sistem identitas bertingkat.

🏷️ Alamat MAC (Fisik)

Identitas permanen dari pabrik (contoh: 00:1A:2B:3C:4D:5E). Seperti sidik jari perangkat, hanya berlaku di jaringan lokal.

📍 Alamat IP (Logis)

Alamat lokasi yang terstruktur (contoh: 142.250.190.78). Bertindak seperti alamat rumah yang mempermudah pengiriman lintas jaringan.

📖 DNS (Domain Name System)

Buku alamat internet yang menerjemahkan nama domain yang mudah diingat manusia menjadi Alamat IP numerik.

3. Dinamika Pengiriman Data & TCP/IP

Data seperti gambar, video, atau halaman web tidak dikirim sekaligus dalam satu berkas utuh, melainkan dipecah menjadi potongan-potongan kecil yang disebut Paket Data.

Analogi Pengiriman Pos Surat ✉️

Bayangkan Anda ingin mengirim buku setebal 1.000 halaman melalui kotak pos yang sempit. Lembaran buku dilepas dan dimasukkan ke dalam 1.000 amplop terpisah. Di luar setiap amplop dituliskan alamat dan nomor halaman. Amplop bisa berjalan melalui rute armada yang berbeda. Saat sampai di tujuan, penerima menyusun kembali lembaran berdasarkan nomor halaman.

📦 IP (Internet Protocol)

Bertanggung jawab membungkus paket data dan memberikan alamat asal & tujuan agar router tahu ke mana paket dikirim.

🤝 TCP (Transmission Control Protocol)

Mengatur penomoran paket, memastikan koneksi awal, dan meminta pengiriman ulang jika ada paket yang hilang di jalan.

4. Arsitektur Klien-Server & Siklus Web

Hampir seluruh aktivitas di internet memanfaatkan model **Klien-Server**.

  • Klien (Client): Perangkat dan peramban web (browser) yang Anda gunakan untuk meminta data.
  • Server: Komputer berkinerja tinggi di pusat data (Data Center) yang menyimpan dan melayani permintaan berkas web.

Siklus Saat Membuka Situs Web:

  1. Pengguna mengetikkan URL di browser (misal: https://developer.mozilla.org).
  2. Browser melakukan pengecekan ke DNS Server untuk mendapatkan IP Server.
  3. Browser membuka koneksi TCP dengan server tujuan.
  4. Browser mengirim pesan permintaan HTTP / HTTPS (GET Request).
  5. Server memproses dan merespons dengan kode status (misal: 200 OK) serta mengirimkan berkas HTML, CSS, & JS.
  6. Browser menerjemahkan (*rendering*) berkas tersebut menjadi tampilan web visual yang Anda lihat.

5. Infrastruktur Fisik Global: Kabel Bawah Laut

Banyak orang mengira internet bekerja utamanya menggunakan satelit luar angkasa. Secara faktual, lebih dari 95% hingga 99% lalu lintas data global ditransmisikan melalui kabel serat optik bawah laut!

🌊 Kabel Serat Optik Bawah Laut

Kapasitas sangat tinggi (ratusan Terabit/detik), latensi sangat rendah, dan membawa sinyal berupa pulsa cahaya di dalam serat kaca setipis rambut.

🛰️ Satelit Komunikasi

Hanya membawa < 0.37% data dunia. Difokuskan untuk daerah terpencil, penerbangan, dan kondisi darurat karena latensinya lebih tinggi.

Di Indonesia, konektivitas internasional ditopang oleh sistem kabel bawah laut seperti SEA-ME-WE, Asia Pacific Gateway (APG), serta dihubungkan antar-pulau melalui Palapa Ring.
